# R-COMP – napodobenina stránky (HTML + CSS)

Cvičný projekt: napodobenina stránky [rcomp.sk](https://www.rcomp.sk) vytvorená len pomocou HTML a CSS (Tailwind).

> **Upozornenie:** Toto je neoficiálny školský/cvičný projekt. Nie je to oficiálna stránka spoločnosti R-COMP s.r.o.
> a nie je s ňou nijako spojený. Formuláre, vyhľadávanie ani košík naozaj nefungujú.

## Obsah

| Priečinok | Popis |
|---|---|
| `stranka/` | hotová stránka bez poznámok v kóde |
| `stranka_s_poznamkami/` | tá istá stránka, ale s poznámkami, ktoré vysvetľujú, čo robí každý väčší blok kódu |

Stránky: `index.html`, `servis.html`, `pre-firmy.html`, `pre-skoly.html`, `internet-a-tv.html`,
`pomoc.html`, `obchod.html`, `kontakty.html`, `informacie.html`, `kosik.html` + spoločný `style.css`.

## Ako to spustiť

1. Stiahni projekt: zelené tlačidlo **Code → Download ZIP** a rozbaľ ho.
2. Otvor `stranka/index.html` (alebo `stranka_s_poznamkami/index.html`) dvojklikom v prehliadači.

Na zobrazenie dizajnu a fotiek je potrebné pripojenie na internet (Tailwind sa načítava cez CDN, fotky z Unsplash).

## Použité

- HTML
- CSS + [Tailwind CSS](https://tailwindcss.com) cez CDN
- fotky z [Unsplash](https://unsplash.com) (voľne použiteľné)
